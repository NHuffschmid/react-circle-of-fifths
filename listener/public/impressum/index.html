2. Keine Erhebung personenbezogener Daten durch den Seitenbetreiber

3. Funktionales Einstellungs-Cookie

Die App setzt ein technisch notwendiges Cookie, um die vom Nutzer kalibrierte Kammertonfrequenz (A4-Referenz in Hz) dauerhaft im Browser zu speichern. Das Cookie enthält ausschließlich einen numerischen Frequenzwert und keinerlei personenbezogene Daten. Es wird nur gesetzt, wenn der Nutzer die Kalibrierungsfunktion aktiv verwendet; ohne Kalibrierung wird kein Cookie gesetzt.

4. Mikrofonzugriff – ausschließlich lokale Verarbeitung

Mikrofondaten werden ausschließlich lokal im Browser verarbeitet.
Audiodaten verlassen das Gerät zu keinem Zeitpunkt. Es werden keine Mikrofondaten an einen Server übertragen.

Die App fordert über die Web Audio API des Browsers Zugriff auf das Mikrofon an. Die Audioverarbeitung (Tonhöhenerkennung / Pitch Detection) findet vollständig auf dem Gerät des Nutzers statt – ohne Verbindung zu externen Servern. Der Browser überträgt ausschließlich die Webseite selbst; Audioinhalte werden zu keinem Zeitpunkt übermittelt.

2. No collection of personal data by the site operator

This web app does not collect, store, or transmit any personal data to the operator. There are no tracking or analytics services.

3. Functional preference cookie

The app sets a single technically necessary cookie to persistently store the concert pitch (A4 reference in Hz) calibrated by the user. 4. Microphone access – local processing only

Microphone data is processed exclusively locally in your browser.
Audio data never leaves your device. No microphone data is transmitted to any server.
